# Cohorts, Retenção e Receita

## Desafio

Analise aquisição, retenção e receita de clientes ao longo do tempo usando SQL analítico.

**Conhecimentos usados:** SQL básico, CTEs, janelas, datas e cohorts.

## Defesa

Faça uma demonstração de cinco minutos e responda a três perguntas técnicas.

## Pergunta de revisão

Você consegue resolver JOINs, CTEs, datas, cohorts e janelas sob limite de tempo?
