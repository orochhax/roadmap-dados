# Projeto — Publicação e apresentação

## Manifesto de entradas

- **Obrigatórias:** dados permitidos, SQL/EDA, pipeline treinado, métricas, limiar, análise de segmentos e limitações.
- **Saídas:** README técnico/executivo, release reproduzível e apresentação.
- **Fallback local:** use demonstração gravada e execução local; hospedagem não é requisito.

## Núcleo essencial

1. [ ] Publique problema, dados, protocolo, resultados, política de decisão e limitações.
2. [ ] Teste instalação e comando em ambiente limpo com `requirements.txt`.
3. [ ] Faça uma demonstração de 8–10 minutos e responda a cinco perguntas sobre leakage, métrica, custo, viés e implantação.

## Concluído quando

- [ ] O README permite reproduzir o resultado sem instrução oral.
- [ ] A release contém código, dependências e artefatos permitidos.
- [ ] A defesa liga decisão, evidência e limitação.
