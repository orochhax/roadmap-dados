# Funções com parâmetros

## Objetivo

Extrair operações repetidas para funções reutilizáveis com parâmetros.

## Conteúdo gratuito

- [Python 3 — Mundo 3](https://www.cursoemvideo.com/curso/python-3-mundo-3/): Aula #20 — Funções, parte 1; exercícios #096 — Função que calcula área, #098 — Função de Contador e #100 — Funções para sortear e somar.

Em cada exercício, leia o enunciado, pause e tente resolver antes de assistir à resolução.

## Aprenda agora

- Dê a cada função uma responsabilidade clara e use nomes iniciados por verbo.
- Trate os parâmetros como o contrato de entrada da função.

## Prática

1. Resolva os exercícios #096, #098 e #100 em arquivos próprios.
2. Complete `01-exercicios/funcoes_relatorio.py`.
3. Chame a mesma função para os três incidentes fornecidos.

## Resultado esperado

As três linhas exibem cidade, duração, clientes afetados e impacto, sem repetir a lógica fora da função.

## Concluído quando

- [ ] Os três exercícios foram tentados antes das resoluções.
- [ ] Uma única função processa os três casos.
- [ ] Você explica a responsabilidade de cada parâmetro.
