# Validação com `while`

## Objetivo

Repetir uma entrada enquanto ela for inválida e manter um menu ativo até a opção de saída.

## Conteúdo gratuito

- [Python 3 — Mundo 2](https://www.cursoemvideo.com/curso/python-3-mundo-2/): Aula #14 — Estrutura de repetição `while`; exercícios #057 — Validação de Dados, #059 — Criando um Menu de Opções e #064 — Tratando vários valores v1.0.

Em cada exercício, leia o enunciado, pause e tente resolver antes de assistir à resolução.

## Aprenda agora

- Normalize entradas textuais com `strip().upper()` antes de validá-las.
- Confira qual condição mantém o laço ativo para evitar repetição infinita.

## Prática

1. Resolva os exercícios #057, #059 e #064 em arquivos próprios.
2. Complete `01-exercicios/validacao_com_while.py`.
3. Teste uma prioridade inválida, uma válida e a opção de encerramento do menu.

## Resultado esperado

Valores fora de `P1`, `P2`, `P3` e `P4` são recusados; o menu encerra somente com a opção definida.

## Concluído quando

- [x] Os três exercícios foram tentados antes das resoluções.
- [x] Uma entrada inválida não encerra nem bloqueia o programa.
- [x] Você explica a condição de permanência de cada `while`.
