# Repetição com `for`

## Objetivo

Usar `range`, filtros, contadores e acumuladores em repetições com quantidade definida.

## Conteúdo gratuito

- [Python 3 — Mundo 2](https://www.cursoemvideo.com/curso/python-3-mundo-2/): Aula #13 — Estrutura de repetição `for`; exercícios #046 — Contagem regressiva, #048 — Soma ímpares múltiplos de três e #050 — Soma dos pares.

Em cada exercício, leia o enunciado, pause e tente resolver antes de assistir à resolução.

## Aprenda agora

- Contador registra quantas vezes algo ocorreu; acumulador soma valores.
- Use uma entrada conhecida para conferir o cálculo manualmente.

## Prática

1. Resolva os exercícios #046, #048 e #050 em arquivos próprios.
2. Complete `01-exercicios/resumo_com_for.py`.
3. Teste com as seis durações indicadas no starter.

## Resultado esperado

Para `110, 45, 70, 95, 125, 30`, o total é `475` e quatro durações são maiores que 60.

## Concluído quando

- [x] Os três exercícios foram tentados antes das resoluções.
- [x] A prática produz total `475` e contagem `4`.
- [x] Você diferencia contador de acumulador.
