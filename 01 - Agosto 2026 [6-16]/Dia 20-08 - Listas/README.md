# Listas

## Objetivo

Inserir, consultar e ordenar valores em uma coleção mutável.

## Conteúdo gratuito

- [Python 3 — Mundo 3](https://www.cursoemvideo.com/curso/python-3-mundo-3/): Aula #17 — Listas, parte 1; exercícios #078 — Maior e Menor valores na Lista, #079 — Valores únicos em uma Lista e #081 — Extraindo dados de uma Lista.

Em cada exercício, leia o enunciado, pause e tente resolver antes de assistir à resolução.

## Aprenda agora

- `sort()` altera a própria lista; `sorted()` produz outra lista.
- Uma atribuição pode criar um alias; use `copy()` quando precisar de uma cópia independente.

## Prática

1. Resolva os exercícios #078, #079 e #081 em arquivos próprios.
2. Complete `01-exercicios/listas_incidentes.py`.
3. Confira valores únicos, mínimo, máximo e ordenação sem alterar os dados originais.

## Resultado esperado

A lista de cidades não contém duplicatas e a lista ordenada não modifica a ordem da lista original.
