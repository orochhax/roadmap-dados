# Critérios de aceitação

- [ ] A tabela contém grupo e resultado para cada observação.
- [ ] A métrica, o efeito mínimo e a regra de decisão estão pré-registrados.
- [ ] O equilíbrio dos grupos foi verificado.
- [ ] O efeito está acompanhado de intervalo.
- [ ] A consulta SQL de validação confere com a análise.
- [ ] O relatório tem no máximo duas páginas e registra resultado, risco e decisão.
