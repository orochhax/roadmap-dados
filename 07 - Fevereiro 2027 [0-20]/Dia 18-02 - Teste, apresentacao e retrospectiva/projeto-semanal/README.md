# Projeto — Teste, apresentação e retrospectiva

## Manifesto de entradas

- **Obrigatórias:** produto executável, fixture, testes, métricas, README e limitações.
- **Saídas:** versão estável, apresentação de cinco minutos e `insumos_tcc.md`.
- **Fallback local:** use fixture e demonstração gravada; serviço externo e IA não são requisitos.

## Núcleo essencial

1. [ ] Execute testes funcionais, de dados e de decisão e corrija falhas críticas.
2. [ ] Apresente problema, decisão, evidência e limitação.
3. [ ] Grave em `insumos_tcc.md` três aprendizados, uma restrição, um risco e suas evidências.

## Concluído quando

- [ ] O fluxo essencial passa em ambiente local limpo.
- [ ] A apresentação demonstra a decisão com resultado reproduzível.
- [ ] `insumos_tcc.md` contém cinco itens apoiados por evidência.
