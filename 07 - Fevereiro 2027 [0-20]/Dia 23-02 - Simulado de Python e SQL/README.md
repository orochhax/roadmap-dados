# Simulado de Python e SQL

## Preparação
- **Pasta/arquivo principal:** `01-exercicios/respostas_python.py` e `01-exercicios/respostas_sql.sql`.
- **Entradas:** `dados/clientes_telecom.csv`, `dados/pedidos.csv` e DuckDB/SQLite. **Fallback local:** fixtures do enunciado.

## Aprenda agora

- **Definição:** simulado mede solução, tempo, explicação e correção; rubrica objetiva separa erro de sintaxe, lógica, dados e comunicação.
- **Exemplo mínimo:** resolva um problema Python e um SQL com cronômetro; reescreva a resposta mais fraca e registre caso de teste que agora passa.
- **Erro comum:** criar plano de revisão sem corrigir nenhuma lacuna verificável nesta sessão.

## Núcleo essencial

1. [ ] Resolva seis questões de Python e seis de SQL sem consulta na primeira tentativa.
2. [ ] Marque confiança e tempo e identifique as duas lacunas mais frequentes.
3. [ ] Reescreva uma solução fraca de cada linguagem e prove a correção com um caso de teste.

## Prática obrigatória

- [ ] **Em `01-exercicios/dia-123-simulado-de-python-e-sql.md`:** Reescreva sem consulta a questão Python com menor confiança e a questão SQL em que gastou mais tempo.
- [ ] **Em `01-exercicios/dia-123-simulado-de-python-e-sql.md`:** Para a lacuna mais frequente, execute uma tarefa de 30 minutos e registre a conferência objetiva.

## Concluído quando
