# Corpus de suporte

Esta pasta contém 15 procedimentos sintéticos para embeddings, busca semântica e RAG. O arquivo `corpus_manifest.csv` registra identificador, origem, licença, versão e SHA-256 de cada documento.

Os documentos são entradas imutáveis. Perguntas, chunks, embeddings, respostas e métricas são produzidos no projeto.
