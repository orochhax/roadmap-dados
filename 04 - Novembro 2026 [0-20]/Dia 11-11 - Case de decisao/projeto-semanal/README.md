# Política de Acionamento por Probabilidade

## Desafio

Crie uma política que decida quem receberá uma intervenção com base em probabilidades e no custo dos erros.

**Conhecimentos usados:** classificação, regressão logística, limiar, calibração e desbalanceamento.

## Entrega mínima

- [ ] Compare curvas e métricas.
- [ ] Defina uma função de custo.
- [ ] Escolha e justifique o limiar.
- [ ] Analise os principais segmentos.

## Prática obrigatória

- [ ] Produza um parecer de risco.

## Defesa

Faça uma demonstração de cinco minutos e responda a três perguntas técnicas.

## Pergunta de revisão

Você consegue defender o limiar do modelo com custo e não apenas usar 0,5?
