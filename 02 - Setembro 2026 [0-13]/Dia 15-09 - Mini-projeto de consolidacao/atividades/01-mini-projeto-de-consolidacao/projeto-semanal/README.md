# Pipeline de Qualidade de Dados Operacionais

## Desafio

Faça a ingestão de arquivos CSV e JSON de fontes diferentes, valide esquema e regras, separe registros aprovados e rejeitados e publique uma base confiável para análise.

**Conhecimentos usados:** Python, arquivos, exceções, módulos e ambientes.

## Defesa

Demonstre que um erro de origem não contamina silenciosamente a base publicada e explique como rastrear cada registro.

## Pergunta de revisão

Você consegue provar quantos registros foram processados, por que alguns foram rejeitados e de onde veio cada dado publicado?
