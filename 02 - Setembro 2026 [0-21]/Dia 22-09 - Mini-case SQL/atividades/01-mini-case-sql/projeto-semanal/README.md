# Banco Comercial e Consultas de Decisão

## Desafio

Modele um pequeno banco de clientes, pedidos e pagamentos e responda a perguntas comerciais reais com SQL.

**Conhecimentos usados:** Python, pandas e SQL básico.

## Defesa

Faça uma demonstração de cinco minutos e responda a três perguntas técnicas.

## Pergunta de revisão

Você consegue responder a perguntas de negócio combinando várias tabelas e validar que os valores não foram duplicados?
