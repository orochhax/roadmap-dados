# Sistema Inteligente de Triagem de Incidentes

## Desafio

Construa uma aplicação de terminal que receba incidentes, valide campos, aplique regras configuráveis de prioridade e produza uma visão gerencial do impacto operacional.

**Conhecimentos usados:** Python básico, condicionais, coleções, funções e Git.

## Defesa

Explique por que a regra de priorização é coerente e mostre um caso em que a ordem das condições altera a decisão.

## Pergunta de revisão

Você consegue transformar regras operacionais em um sistema configurável, testável e útil para priorizar recursos?
