# Wi-Fi com baixa velocidade

- **Documento:** DOC-03
- **Versão:** 1.0
- **Licença:** conteúdo sintético para estudo

## Procedimento

Faça o teste próximo ao roteador, pause downloads e compare as redes de 2,4 GHz e 5 GHz. A rede de 5 GHz é indicada para menor distância.

## Limite de atendimento

Se o procedimento não resolver ou houver risco, registre o caso e encaminhe para revisão humana.
