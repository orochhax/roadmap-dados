# Proteção de dados pessoais

- **Documento:** DOC-13
- **Versão:** 1.0
- **Licença:** conteúdo sintético para estudo

## Procedimento

Nunca registre senha, número completo de cartão ou documento desnecessário. Compartilhe dados somente com perfis autorizados.

## Limite de atendimento

Se o procedimento não resolver ou houver risco, registre o caso e encaminhe para revisão humana.
